# Himawari-9 image CDN (Cloudflare)

แปลงภาพดาวเทียม Himawari-9 Band 13 จาก NOAA/AWS **เพียงครั้งเดียวต่อภาพ** ด้วยงานตั้งเวลา (cron ทุก 1 นาที)
เก็บ PNG ไว้ใน R2 แล้วให้ผู้ใช้ทุกคนดาวน์โหลดไฟล์สำเร็จรูปผ่าน CDN ของ Cloudflare
ผู้ใช้จึงไม่ต้องรอ Worker แปลงภาพ และจำนวนผู้ใช้ไม่เพิ่มภาระการแปลงภาพ

- ภาพใหม่จะถูกแปลงก่อน แล้วค่อยเติมย้อนหลังจนครบ 5 ชั่วโมง (31 ภาพ) ภาพที่เก่าเกิน 6 ชั่วโมงจะถูกลบ
- รับเฉพาะภาพที่เผยแพร่ครบทั้ง 3 segment เวลาภาพมาจากชื่อไฟล์ AWS เท่านั้น ไม่มีการสร้างภาพเติมช่องว่าง
- ภาพเป็น PNG แบบ palette 255 ระดับอุณหภูมิ (ห่างกันราว 0.58 °C) ขนาดประมาณ 1/4–1/5 ของ PNG แบบ RGBA เดิม
- `index.json` แคช 15 วินาที ไฟล์ภาพแคชถาวร (immutable) เพราะชื่อไฟล์คือเวลาถ่าย

## ติดตั้ง (ทำบนเครื่องของคุณ)

1. มีบัญชี Cloudflare และเปิด **Workers Paid** (ประมาณ 5 USD/เดือน) เพราะการแปลงภาพหนึ่งภาพใช้ CPU หลายวินาที แผนฟรีจำกัด CPU ไว้ 10 ms
2. `npx wrangler login`
3. `npx wrangler r2 bucket create lao-himawari-frames`
4. `cd cloudflare` แล้ว `npx wrangler deploy`
5. รอประมาณ 10 นาที แล้วเปิด `https://<ชื่อ worker>.<บัญชี>.workers.dev/health` ควรเห็น `frames` ใกล้ 31 และ `ageMinutes` ประมาณ 12–14
6. **สำหรับผู้ใช้จำนวนมาก (แนะนำ):** ใน Cloudflare Dashboard → R2 → `lao-himawari-frames` → Settings
   - Custom Domains: ผูกโดเมนย่อย เช่น `himawari.<โดเมนของคุณ>` (โดเมนต้องอยู่ใน Cloudflare)
   - CORS policy: วางเนื้อหาไฟล์ `r2-cors.json`
   ไฟล์จะถูกเสิร์ฟจาก CDN โดยตรง ไม่ต้องเรียก Worker ทุกครั้ง ทำให้ค่าใช้จ่ายไม่โตตามจำนวนผู้ใช้
   (ถ้ายังไม่มีโดเมน ใช้ที่อยู่ workers.dev ได้ แต่ทุกคำขอจะนับเป็นคำขอ Worker)
7. ใส่ที่อยู่ในไฟล์ `dist/aws-satellite.js` ของเว็บ เช่น
   `export const CLOUD_CDN_BASE='https://himawari.<โดเมนของคุณ>';`
   แล้วรัน `node build-radar-site.mjs` และสคริปต์ตรวจ จากนั้น push และ deploy เว็บตามปกติ

ถ้า CDN ใช้ไม่ได้ เว็บจะกลับไปใช้เส้นทางเดิม `/api/satellite/aws/...` ของ Sites โดยอัตโนมัติ (เส้นทางนั้นยังแปลงภาพตามคำขอ เหมาะกับผู้ใช้ไม่มาก)

## ตรวจ

`node verify-cdn.mjs` (จากโฟลเดอร์หลักของโปรเจกต์) ใช้ไฟล์ HSD สังเคราะห์ขนาดเล็ก ไม่ใช่ข้อมูลจริง

## ข้อจำกัด

- ภาพจะเก่ากว่าเวลาถ่ายอย่างน้อยประมาณ 12 นาที ตามเวลาที่ NOAA/AWS เผยแพร่ (วัดจริง 11:44–12:13 นาที เมื่อ 9 ต.ค. 2026)
- ส่วนนี้รองรับเฉพาะภาพเมฆ Himawari เรดาร์ RainViewer, Open-Meteo และ Gemini มีเงื่อนไขการใช้งานและโควตาแยกต่างหาก ต้องจัดการก่อนเปิดเว็บเป็นสาธารณะ
- เว็บบน Sites ยังเป็นแบบส่วนตัวเหมือนเดิม การเปิดสาธารณะเป็นการตัดสินใจแยกต่างหาก
